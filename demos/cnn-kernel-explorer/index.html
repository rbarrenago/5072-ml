▶ Konboluzioa benetan nola eraikitzen da?

Kernel 3×3-k irudiaren 3×3 eremu bat hartzen du, biderketak egin eta dena batzen du. Emaitza bakar hori feature map-eko gelaxka batean idazten da.

🧠 Hiru kontzeptuak esaldi bakarrean

FEATURE MAP
“Kernelak bilatzen duen patroia non eta zenbat agertu den erakusten duen mapa.”
ReLU
“Erantzun negatiboak 0 bihurtzen ditu eta seinale positiboak uzten ditu.”
MAXPOOL
“Auzo bakoitzean aktibazio handiena gordetzen du, mapa txikiago eta trinkoago bihurtuz.”

Gogoratzeko istorioa

1. Irudia daukat.
2. Kernel batek patroi bat bilatzen du.
3. Feature map-ak “non aurkitu dut?” esaten du.
4. ReLU-k erantzun negatiboak kentzen ditu.
5. MaxPool-ek informazio indartsuena laburbiltzen du.
