2 · Conv1: nork sortzen ditu filtroak?

Demo honetan hiru filtro erraz aukeratu ditugu intuizioa eraikitzeko. CNN erreal batean, ordea, filtroen pisuak entrenamenduan ikasten dira.

🧑‍💻 Guk aukeratzen dugu · hiperparametroak Filtro kopurua, kernel tamaina (3×3), stride-a, padding-a, geruza kopurua...
🧠 Sareak ikasten du · parametroak Filtro bakoitzeko 3×3 pisuak eta bias-a, backpropagation + gradient descent bidez.
Zergatik bertikala, horizontala eta diagonala? Ez direlako “CNN batek derrigor ikasten dituen hiru filtroak”. Didaktikoki aukeratu ditugu, lehen geruzetako patroi sinpleak erraz ikusteko. Sare erreal batek datuetarako erabilgarriak diren filtroak ikasiko ditu, eta ez dute beti izen errazik izango.

3 · Filtro bakoitza: Conv → Feature map → ReLU

Hiru filtroetako bakoitzarekin prozesu bera egiten da. Lehenik feature map gordina sortzen da; gero ReLU aplikatzen da.

Kontuz: ReLU-k ez du filtro berririk sortzen. Filtroak sortutako feature map-ari aplikatzen zaion aktibazio-funtzioa da: ReLU(x)=max(0,x).

4 · Conv2: bigarren hidden layer-ak zer egiten du?

Bigarren geruzak ez du jatorrizko irudia zuzenean jasotzen. Lehen geruzako hiru ReLU feature map-ak jasotzen ditu. Conv2-ko filtro bakoitzak hiru kanal horiek batera erabiltzen ditu feature berri bat eraikitzeko.

Horregatik kendu ditugu “Forma / izkinak” eta “Egitura konbinatua” izen anbiguoak. Hemen Feature A eta Feature B deituko diegu. Sare erreal batean feature sakon baten esanahia ez da beti hitz bakar batez deskribatzeko modukoa.

6 · Flatten + Dense + Softmax = MLP sailkatzailea

CNNak feature-ak atera eta trinkotu ditu. Orain feature horiek bektore bihurtu, Dense hidden layer batera bidali eta azken Dense(4) geruzarekin lau klaseetako logits-ak sortzen ditugu.

Flatten feature-ak Dense hidden neurons Output logits
Hau ezagutzen duzue: azken zatia MLP arrunt baten logika da. Aldea da input-a ez direla pixel gordinak; CNNak ikasitako feature-ak dira.

7 · Softmax: 4 output neuron → 4 probabilitate

Azken Dense geruzak lau logit sortzen ditu: bat klase bakoitzeko. Softmax-ek logits horiek probabilitate-banaketara bihurtzen ditu.

Simulazio didaktikoa: padding, convolutions, ReLU eta MaxPool nabigatzailean kalkulatzen dira. Demo honek ez du modeloa entrenatzen; Dense-ren azken logits-ak adibidea argi uzteko simulatuak dira.

🧠 Istorio osoa esaldi batean

Irudia → Conv filtroek patroi lokalak neurtzen dituzte → feature map gordinak → ReLU → geruza sakonagoek aurreko feature-ak konbinatzen dituzte → MaxPool → Flatten → MLP (Dense) → logits → Softmax probabilitateak.
