⚽ Futbolariaren balioa: OLS vs Ridge vs Lasso

EA SPORTS FC estiloko ezaugarriak erabiliz, hiru erregresio-modeloek koefizienteak nola ikasten dituzten eta MAE · RMSE · R² geroago nola erabiltzen diren ebaluatzeko ikusiko dugu.

3 · PREDIKZIOAMerkatu-balioa (M€)

⚠️ Ridge eta Lasso MODELOAK dira. MAE, RMSE eta R² METRIKAK dira. Ez dira maila bereko kontzeptuak.

1 · Sortu zure futbolaria

Aldatu atributuak edo aukeratu profil bat. Helburua ez da FIFA/EA FC-ren balio ofiziala kalkulatzea: erregularizazioa ulertzeko dataset sintetiko didaktiko bat erabiltzen dugu.

2 · Erregularizazioaren indarra

α = 0 → erregularizaziorik ez. α handitzean Ridge eta Lasso koefizienteak gehiago kontrolatzen saiatzen dira.

α = 0.15

Ridge · L2

errorea + α · Σw²

Koefizienteen magnitude orokorra kontrolatzen du; korrelazioa dagoenean pisuen banaketa ere alda daiteke. Normalean ez ditu koefizienteak zehazki 0 bihurtzen.

Lasso · L1

errorea + α · Σ|w|

Koefizienteak txikitu eta batzuk zehazki 0 bihur ditzake.

3 · Futbolari honen predikzioa

OLS

—
Errorea minimizatzen du, zigorrik gabe.

Ridge

—
Koefizienteak egonkortu / txikitu.

Lasso

—
Koefiziente batzuk 0 izan daitezke.

4 · Zer gertatu da koefizienteekin?

Ezaugarriak estandarizatuta daude. Horregatik koefizienteak eskala berean konpara daitezke. Balioek ereduaren barruko pisua adierazten dute, ez futbolaren munduko “benetako garrantzia”.

5 · Eta MAE · RMSE · R²?

Orain bai: modeloak entrenatu eta predikzioak egin ondoren, TEST multzoan ebaluatu ditzakegu. Metrikek ez dituzte koefizienteak ikasten; modeloa zenbateraino dabilen ondo neurtzen dute.

ModeloaMAE ↓RMSE ↓R² ↑
Gogoratu: OLS / Ridge / Lasso = modelatzeko moduak. MAE / RMSE / R² = ebaluatzeko moduak.

6 · Pentsatzeko galderak

① Lasso-k DEF = 0 jartzen badu, defendatzea futbolean ez dela garrantzitsua esan nahi du?

Ez. Dataset honetan eta beste feature guztiak kontuan hartuta, modeloak balioa iragartzeko DEF aparteko informazio nahikorik behar ez duela esan dezake.

② Zergatik izan daiteke Ridge interesgarria OVR, PAC, SHO, PAS eta DRI elkarren artean erlazionatuta badaude?

Ridge-k informazioa ezaugarri korrelazionatuen artean modu egonkorragoan banatzeko joera du.

③ α oso handia jartzea beti hobea al da?

Ez. Erregularizazio gehiegi → koefiziente gehiegi txikitu → underfitting arriskua.
