MNIST MLP Lab

Pixels → Flatten → Dense → Softmax. Ikusi nola MLP batek 28×28 irudi bat 784 dimentsioko bektore bihurtzen duen, eta zergatik den hori CNN-etarako zubi naturala.

1 · 28×28 irudia

Aukeratu digitu bat. Demoak MNIST estiloko lagin sintetikoak erabiltzen ditu mekanismoa modu bisualean azaltzeko.

MNIST: 28×28 = 784 pixel. Pixel-balioak normalean [0,255] → [0,1] normalizatzen dira.

2 · Flatten → 784 features

MLP-ak irudia bektore lau bihurtzen du. Hemen lehen 48 balioak bakarrik erakusten dira.

shape = (28, 28)
Sakatu FLATTEN.
28×28→Flatten→784→Dense

🤔 Zer galdu dugu?

784 balioak mantentzen ditugu, baina MLP dentsuak ez du irudiaren egitura espaziala berez aprobetxatzen: zein pixel dagoen zeinen ondoan ikasi behar du pisuen bidez.

3 · MLP arkitektura

Laneki-ko oinarrizko arkitektura bera:

Input784pixel / feature
Dense + ReLU128hidden neurons
Dense + ReLU64hidden neurons
Softmax100…9 klaseak
Parametroak: 100,480 + 8,256 + 650 = 109,386.
Gakoa: MLP honek irudia sailka dezake, baina lehenengo 28×28 egitura flatten egiten du.

5 · MLP → CNN zubia

MLP-ak emaitza ona lor dezake MNIST bezalako problema sinple batean. Baina irudiek egitura espaziala dute, eta horixe da CNN-ek zuzenean aprobetxatzen dutena.

MLP

  • 28×28 → 784 flatten
  • Fully connected konexio asko
  • Pixel-posizioen erlazioak pisuen bidez ikasi behar ditu

CNN

  • 28×28 egitura mantendu
  • Kernel lokalak + weight sharing
  • Ertzak, formak eta patroi espazialak modu naturalagoan ikasi
